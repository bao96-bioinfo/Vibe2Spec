# Copy contract

Copy the exact approved JSON array from artifacts/input.json to artifacts/output.json. Preserve values and order. Do not mutate the input. Missing input or contents differing from the approved input stop without an output. No retry or fallback is allowed. The fictional example-copy tool performs exactly one call within the approved resource limits. Runtime is fictional-copy-1 and platform is fictional. There are no environment variables, random choices, or concurrent operations.
