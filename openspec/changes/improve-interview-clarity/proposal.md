# Proposal

## Why

The user finds Vibe2Spec's questions harder to understand than Superpowers' questions. Existing guidance requires complete explanations but does not adequately control unfamiliar concepts per turn, reuse approved context, or evaluate recovery from confusion.

## What Changes

The coordinator will introduce one unfamiliar decision at a time, explain observable consequences, and justify recommendations using the project. Familiar independent settings remain eligible for grouped review. Approved context supplies already settled answers; unapproved drafts and examples remain unapproved. Technical records preserve the exact meaning of understandable decisions.

Evaluation will add multi-turn scenarios, a separate assessment rubric, retained independent responses, and explicit limits on claims about human comprehension. Public examples and the generated plugin will follow the policy.

The user's subsequent Friendly Technical Explainer instructions add answer-first explanations, a short onboarding overview, motivation before procedure, concrete definitions that retain source terminology, source-order walkthroughs, scannable formatting, and verified file-based evidence. These explanation preferences supersede the earlier no-bold and no-list rules for user-facing explanations. They are incorporated directly into Vibe2Spec without a separate skill installation.

## Capabilities

### New Capabilities

- `interview-comprehension`: Conversation pacing, context reuse, explanation repair, and behavioral evaluation of informed decisions. This supplements request discovery in the completed, unarchived release change; no main capability specifications have been archived yet.

### Modified Capabilities

None in the main specification store.

## Impact

Changes affect the coordinator skill, interview and authoring guidance, illustrated documentation, evaluation fixtures and evidence, and generated package copies. Record schemas, validation APIs, acceptance gates, and accepted Step 1 artifacts retain their current definitions. No new runtime dependency is needed.
